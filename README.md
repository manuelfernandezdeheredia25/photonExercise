# Batalla De Tanques 
### Ejercicio de Photon para clase de Redes e IA

## Act. Prototipo Multijugador - Pequeño Documento Postmortem


TÍTULO DEL PROTOTIPO: Batalla de Tanques

INTEGRANTES DEL GRUPO: Álvaro, Andrés, Manu

MOTOR DE JUEGO: Unity 6000.0.59f2



## HERRAMIENTAS USADAS
Modelos producidos por el equipo, texturas de tanques renderizadas por el equipo, texturas del entorno de Polyhaven y FreeStylized

Blender para modelos 3D y creación de texturas

## DESCRIPCIÓN DEL JUEGO
Juego de combate con tanques multijugador. Derriba los tanques enemigos para aumentar tu puntuación. 

El primero en alcanzar 1000 puntos gana la partida.

Máximo 4 jugadores por partida. 

Puedes elegir entre tres variedades de tanque con diferentes atributos:
- Tanque Equilibrado
- Tanque Ligero
- Tanque Pesado

## JUGABILIDAD
WASD o flechas direccionales para moverse, apuntar con el ratón, clic izquierdo del ratón para disparar. Las balas pueden rebotar en las paredes. El host puede añadir bots a la partida para rellenar huecos.
